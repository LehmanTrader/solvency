# Composer role glyphs

Custom text-message-style role badges for the Build Composer org-chart UI
(operator's picks from the 2026-08-26 candidate sheet: E1, K1, R1).

| File | Role | Depicts |
|---|---|---|
| conductor.png | Orchestrator | Conductor, baton raised (no real emoji exists for this) |
| worker.png | Worker | Builder in a yellow hard hat with a wrench |
| fallback.png | Fallback | Orange-and-white lifebuoy with rope |

Provenance: generated for Solvency on 2026-08-26 with Google's Nano Banana 2
image model via fal.ai (prompt-engineered to the Apple-message emoji register;
originals in the operator's private design archive). worker.png had a stray
letter on the helmet removed by local pixel edit. Backgrounds removed and
cropped square locally; 128×128 RGBA, displayed at 24 px inside .cp-badge.
These are Solvency-commissioned assets, not Apple emoji artwork; the Unicode
fallbacks (🧭 🛠️ 🛟) remain in code for text-only contexts.
